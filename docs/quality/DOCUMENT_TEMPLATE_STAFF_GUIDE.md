# Changing a document design: staff guide

For AFN staff. No technical knowledge needed. You can restyle any of the six documents, or add a new kind of document, with a Word file.

## The idea in one minute

1. Get a Word file: download the current design (or AFN's original design), or a blank starter for a new document.
2. Change how it looks in Word: logo, fonts, colours, layout.
3. Where you want information filled in, type its name in square brackets, for example **[Client Name]**.
4. Upload it. AFN checks it and tells you in plain words if anything is missing.
5. Click **Use this design**. New documents use it from then on. Documents already made are not changed.

## Where to find it

Documents page, then **Template library**. Pick the document type on the left. The **Fields you can use** box shows every name you may type, each with a **Copy** button.

## Step by step: restyle one of the six documents

1. Open **Template library** and choose the document, for example Quotation Proposal.
2. Click **Download the design in use**. If the document still uses AFN's built-in layout, the button is **Download the original design** instead. Open the file in Word.
3. Change the look. Keep the tables as they are (see "Tables" below). Keep the fields you still want printed.
4. Save it as a Word file (.docx).
5. Under **Replace source document**, drop the file in, add a short note, and click **Save version**.
6. Read the **checklist** under the new version. Green means found. Red means something required is missing, and the line under it says what to do.
7. When it says **This design is ready to use**, click **Use this design**.
8. Optional: pick a ticket and click **Test DOCX** first to see a real sample without saving anything.

If you make a mistake, the previous design stays in use until you click **Use this design** on a good one. To go back later, click **Roll back** on the older version.

## Step by step: add a new kind of document

1. Click **New document type**. Give it a name and say which AFN record fills it (usually the ticket). Click **Create document type**.
2. On the document, click **Download a blank starter file**. It already lists every field.
3. Restyle it in Word, keeping each [Field Name] where you want that information.
4. Upload it as a design.
5. If the checklist shows **New fields to add** (names you invented, such as [Site Note]), click **Add as fields**. Staff fill these in when they create the document.
6. Click **Use this design**. The new document now appears next to the other six on the Documents page.

## Already have a finished design with blank lines?

If your Word file has lines like **Client Name: ________** or just **Ticket Number:**, the checklist shows **Blanks that can become fields**. Click **Fill these blanks**. AFN saves a new version with those lines turned into fields; your uploaded file is kept. Only names AFN recognises are offered, so ordinary lines like "Remarks: ____" stay as they are. Check the new version's checklist, then click **Use this design**.

## PDF designs

If your design is a PDF saved from Word or another program (not a scan), AFN looks for labels such as **Client Name:** and offers **Fields AFN can place for you**. Click **Place these fields**, then **Set up fields** to check each box. Drag a box or use the arrow buttons if it is a little off. Then click **Use this design**. A scanned PDF is just a picture, so there is nothing to detect: click on the page where each value should appear instead.

## Removing a document type

Open the document type and click **Disable document** to hide it (its history is kept), or **Delete document type** to remove it completely. Delete only works for a type that has never been used to make a document. The six built-in documents cannot be deleted.

## What you can type

Type the name in square brackets, spelled as shown in **Fields you can use**: **[Client Name]**, **[Ticket Number]**, **[Technician Name]**, **[Service Date]** and so on. Capital letters do not matter. A few everyday words also work, such as [Customer] or [Phone].

Square brackets that are not field names (like [Signature] or [1]) print exactly as typed.

## Tables

Rows that repeat (the price table, the equipment list, the readings) are special: they have hidden start and end markers and their own column fields. Keep these tables from AFN's design and only change how they look (fonts, colours, widths). Rebuilding one from scratch is a technical job; ask your system administrator.

## When something is red

| What the checklist says | What to do |
| --- | --- |
| A table is **not found** | You removed or changed a repeating table. Start again from the downloaded design and keep that table, or ask your system administrator. |
| **Some field names are not recognised** | A name is misspelled or not offered for this document. Compare with the Fields box. |
| **New fields to add** (new document types only) | Click **Add as fields**, or fix the spelling if it was a typo. |
| The file is refused | Use a normal .docx without macros, links to other files, or embedded objects. |

## What this never changes

Changing a design only changes how a document looks. It never changes quotation totals, deposits, acceptance, or any ticket data. Documents already generated keep the design they were made with.

## Who can do what

Uploading a design, checking it, publishing it (**Use this design**, **Roll back**) and creating or deleting document types are separate permissions, set by the administrator. **Use this design** switches a new document type on only for staff who may also manage document types; otherwise an administrator switches it on.
